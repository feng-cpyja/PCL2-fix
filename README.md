## 使用

下载 `Plain Craft Launcher 2.exe`，放到任意目录双击运行即可。首次运行会在同目录生成 `PCL` 配置文件夹。

> 建议不要使用启动器内置的「自动更新」，否则会覆盖回官方版本。
